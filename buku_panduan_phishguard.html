1. Gambaran Aplikasi

Tampilan Aplikasi Deteksi Phishing Berbasis URL “PhishGuard”

PhishGuard adalah aplikasi berbasis web yang dirancang untuk mendeteksi potensi ancaman phishing pada alamat tautan website (URL). Pengguna cukup memasukkan atau menempelkan URL yang mencurigakan ke dalam form pemindai, kemudian sistem akan menganalisis karakteristik struktural dan leksikal dari tautan tersebut tanpa perlu mengunjungi website tujuan secara langsung. Sistem secara otomatis menyajikan hasil klasifikasi apakah tautan tersebut berstatus Legitimate (aman) atau Phishing (berbahaya), dilengkapi skor probabilitas keyakinan model, skor risiko (0–100), tingkat bahaya, dan daftar anomali struktural URL.

Aplikasi ini mengadopsi arsitektur terpisah antara antarmuka web dan mesin kecerdasan buatan. Sisi portal web dibangun menggunakan Laravel 12 (PHP 8.3+) yang menangani autentikasi pengguna, manajemen hak akses (RBAC), panel kendali admin, dan persistensi data MySQL. Sisi mesin inferensi cerdas dijalankan oleh FastAPI (Python) yang mengekstrak 49 fitur leksikal dari string URL secara instan dan mengeksekusi model klasifikasi machine learning.

Arsitektur dan Alur Kerja Sistem

Alur pemrosesan data di dalam sistem PhishGuard melibatkan integrasi antarmuka web, lapisan middleware otorisasi, controller, service layer HTTP internal, hingga engine machine learning Python:

  1. Pengguna memasukkan alamat URL pada halaman Scanner, formulir divalidasi oleh ScanUrlRequest untuk memastikan sanitasi URL dan batasan panjang maksimal 2.048 karakter.
  2. PhishGuardService mengirimkan URL target ke endpoint POST /predict milik FastAPI melalui koneksi HTTP loopback lokal terproteksi.
  3. Mesin FastAPI memanggil modul url_features.py untuk mengekstrak 49 dimensi fitur leksikal secara client-side (tanpa request DNS/jaringan luar).
  4. Vektor fitur diumpankan ke model Machine Learning aktif untuk menghitung probabilitas phishing.
  5. FastAPI mengembalikan struktur data JSON yang memuat prediksi, skor risiko, keyakinan model, dan temuan indikator anomali.
  6. Kelas PredictionResult di Laravel memverifikasi kesesuaian kontrak skema data sebelum disimpan. Jawaban yang tidak valid akan ditolak secara ketat.
  7. ScannerController menyimpan hasil pemindaian ke tabel scans dan mencatat jejak audit ke tabel activity_logs.
  8. Antarmuka web menyajikan kartu hasil analisis risiko dan rincian indikator kepada pengguna secara informatif.

"""Ekstraksi fitur URL PhishGuard.

Aturan:
- Hanya memakai string URL. Tidak ada akses jaringan (DNS, WHOIS, HTTP) dan tidak ada
  pembacaan file eksternal.
- File ini dipakai IDENTIK oleh training (Colab) dan inferensi (FastAPI).
- Mengubah fitur, urutan fitur, atau definisi fitur WAJIB menaikkan EXTRACTOR_VERSION.
- URL tanpa skema diberi "http://" oleh normalize_url() sebelum fitur dihitung (v1.1).
"""
from __future__ import annotations

import ipaddress
import math
import re
from collections import Counter
from itertools import groupby
from urllib.parse import urlsplit

EXTRACTOR_VERSION = "1.2"

FEATURE_NAMES: list[str] = [
    # Panjang
    "length_url", "length_hostname",
    # Hostname berupa IP
    "ip",
    # Jumlah karakter khusus pada URL
    "nb_dots", "nb_hyphens", "nb_at", "nb_qm", "nb_and", "nb_or", "nb_eq",
    "nb_underscore", "nb_tilde", "nb_percent", "nb_slash", "nb_star", "nb_colon",
    "nb_comma", "nb_semicolon", "nb_dollar", "nb_space",
    # Istilah umum
    "nb_www", "nb_com", "nb_http", "nb_dslash",
    # Protokol, rasio digit, punycode, port
    "is_https", "ratio_digits_url", "ratio_digits_host", "punycode", "has_port",
    # Posisi TLD dan struktur subdomain
    "tld_in_path", "tld_in_subdomain", "abnormal_subdomain", "nb_subdomains", "prefix_suffix",
    # Layanan pemendek URL dan ekstensi path
    "shortening_service", "path_extension",
    # Statistik kata
    "length_words_raw", "char_repeat",
    "shortest_words_raw", "shortest_word_host", "shortest_word_path",
    "longest_words_raw", "longest_word_host", "longest_word_path",
    "avg_words_raw", "avg_word_host", "avg_word_path",
    # Kata kunci mencurigakan dan keacakan hostname
    "phish_hints", "entropy_host",
]

COMMON_TLDS = frozenset({
    "com", "net", "org", "edu", "gov", "info", "biz", "io", "xyz", "top", "site",
    "online", "shop", "app", "dev", "uk", "de", "ru", "cn", "jp", "fr", "br", "au", "us",
})

SHORTENERS = frozenset({
    "bit.ly", "goo.gl", "tinyurl.com", "t.co", "ow.ly", "is.gd", "buff.ly", "adf.ly",
    "bit.do", "cutt.ly", "rebrand.ly", "shorturl.at", "tiny.cc", "rb.gy", "lnkd.in",
    "t.ly", "v.gd", "tr.im", "x.co", "soo.gd",
})

PHISH_HINTS = (
    "login", "signin", "verify", "update", "secure", "account", "bank", "confirm",
    "password", "paypal", "webscr", "wallet", "billing", "support", "suspend",
    "alert", "authenticate",
)

_WORD_SPLIT = re.compile(r"[^A-Za-z0-9]+")
_ABNORMAL_SUBDOMAIN = re.compile(r"w[w]?[0-9]*")
_INTEGER_HOST = re.compile(r"0x[0-9a-f]+|\d{8,10}")
_TLD_IN_PATH = re.compile(r"\.(?:" + "|".join(sorted(COMMON_TLDS)) + r")(?![a-z0-9])")


_SCHEME = re.compile(r"^[A-Za-z][A-Za-z0-9+.\-]*://")


def normalize_url(url) -> str:
    """Bentuk kanonik URL untuk ekstraksi: buang spasi tepi dan pastikan ada skema.

    URL pada dataset training berskema (http:// atau https://). URL tanpa skema (mis. "example.com/a")
    diberi "http://" agar fitur yang bergantung pada skema (is_https, nb_slash, nb_dslash, nb_http,
    length_url) tidak keluar dari distribusi training. Skema yang sudah ada tidak diubah.
    """
    raw = "" if url is None else str(url).strip()
    if not raw:
        return ""
    if raw.startswith("//"):
        return "http:" + raw
    if not _SCHEME.match(raw):
        return "http://" + raw
    return raw


def _split_url(url: str) -> tuple[str, str, bool, str]:
    """Kembalikan (url_mentah, hostname, ada_port, path). Tidak pernah melempar error."""
    raw = url.strip()
    candidate = raw if _SCHEME.match(raw) else "http://" + raw
    try:
        parts = urlsplit(candidate)
        host = (parts.hostname or "").lower()
        try:
            has_port = parts.port is not None
        except ValueError:
            has_port = True  # ada penanda port tetapi nilainya tidak valid
        return raw, host, has_port, parts.path
    except ValueError:
        # Cadangan manual untuk URL yang tidak dapat di-parse (mis. IPv6 rusak)
        rest = raw.split("://", 1)[-1]
        netloc = re.split(r"[/?#]", rest, maxsplit=1)[0]
        hostport = netloc.rsplit("@", 1)[-1]
        host = hostport.split(":")[0].lower()
        path = re.split(r"[?#]", rest[len(netloc):], maxsplit=1)[0]
        return raw, host, ":" in hostport, path


def _is_ip(host: str) -> bool:
    if not host:
        return False
    try:
        ipaddress.ip_address(host)
        return True
    except ValueError:
        return bool(_INTEGER_HOST.fullmatch(host))


def _words(text: str) -> list[str]:
    return [w for w in _WORD_SPLIT.split(text) if w]


def _word_stats(words: list[str]) -> tuple[int, int, int, float]:
    if not words:
        return 0, 0, 0, 0.0
    lengths = [len(w) for w in words]
    return len(words), min(lengths), max(lengths), sum(lengths) / len(lengths)


def _digit_ratio(text: str) -> float:
    if not text:
        return 0.0
    return sum("0" <= ch <= "9" for ch in text) / len(text)


def _entropy(text: str) -> float:
    if not text:
        return 0.0
    total = len(text)
    return -sum((n / total) * math.log2(n / total) for n in Counter(text).values())


def extract_url_features(url: str) -> dict[str, float]:
    """Hitung fitur dari satu URL. Urutan kunci selalu sama dengan FEATURE_NAMES."""
    raw, host, has_port, path = _split_url(normalize_url(url))
    lower = raw.lower()
    path_lower = path.lower()

    is_ip = _is_ip(host)
    labels = host.split(".") if host else []
    sub_labels = labels[:-2] if (labels and not is_ip) else []

    url_words = _words(raw)
    host_words = _words(host)
    path_words = _words(path)
    n_url, short_url, long_url, avg_url = _word_stats(url_words)
    _, short_host, long_host, avg_host = _word_stats(host_words)
    _, short_path, long_path, avg_path = _word_stats(path_words)

    f = {
        "length_url": len(raw),
        "length_hostname": len(host),
        "ip": int(is_ip),
        "nb_dots": raw.count("."),
        "nb_hyphens": raw.count("-"),
        "nb_at": raw.count("@"),
        "nb_qm": raw.count("?"),
        "nb_and": raw.count("&"),
        "nb_or": raw.count("|"),
        "nb_eq": raw.count("="),
        "nb_underscore": raw.count("_"),
        "nb_tilde": raw.count("~"),
        "nb_percent": raw.count("%"),
        "nb_slash": raw.count("/"),
        "nb_star": raw.count("*"),
        "nb_colon": raw.count(":"),
        "nb_comma": raw.count(","),
        "nb_semicolon": raw.count(";"),
        "nb_dollar": raw.count("$"),
        "nb_space": raw.count(" ") + lower.count("%20"),
        "nb_www": lower.count("www"),
        "nb_com": lower.count(".com"),
        "nb_http": lower.count("http"),
        "nb_dslash": raw.count("//"),
        "is_https": int(lower.startswith("https://")),
        "ratio_digits_url": _digit_ratio(raw),
        "ratio_digits_host": _digit_ratio(host),
        "punycode": int("xn--" in lower),
        "has_port": int(has_port),
        "tld_in_path": int(bool(_TLD_IN_PATH.search(path_lower))),
        "tld_in_subdomain": int(any(label in COMMON_TLDS for label in sub_labels)),
        "abnormal_subdomain": int(any(_ABNORMAL_SUBDOMAIN.fullmatch(label) for label in sub_labels)),
        "nb_subdomains": len(sub_labels),
        "prefix_suffix": int("-" in host),
        "shortening_service": int(
            host in SHORTENERS or any(host.endswith("." + s) for s in SHORTENERS)
        ),
        "path_extension": int(path_lower.endswith((".txt", ".exe", ".js"))),
        "length_words_raw": n_url,
        "char_repeat": max((len(list(g)) for _, g in groupby(raw)), default=0),
        "shortest_words_raw": short_url,
        "shortest_word_host": short_host,
        "shortest_word_path": short_path,
        "longest_words_raw": long_url,
        "longest_word_host": long_host,
        "longest_word_path": long_path,
        "avg_words_raw": avg_url,
        "avg_word_host": avg_host,
        "avg_word_path": avg_path,
        "phish_hints": sum(lower.count(word) for word in PHISH_HINTS),
        "entropy_host": _entropy(host),
    }
    return {name: f[name] for name in FEATURE_NAMES}


def extract_feature_vector(url: str) -> list[float]:
    """Vektor fitur dengan urutan FEATURE_NAMES (dipakai FastAPI saat prediksi)."""
    features = extract_url_features(url)
    return [float(features[name]) for name in FEATURE_NAMES]

class PredictRequest(BaseModel):
    url: str = Field(..., max_length=2048, description="URL lengkap dengan skema http:// atau https://")

    @field_validator("url")
    @classmethod
    def validasi_url(cls, value: str) -> str:
        value = value.strip()
        if not URL_PATTERN.fullmatch(value) or any(ord(ch) < 32 or ord(ch) == 127 for ch in value):
            raise ValueError("URL tidak valid.")
        try:
            host = urlsplit(value).hostname
        except ValueError as exc:
            raise ValueError("URL tidak valid.") from exc
        if not host:
            raise ValueError("URL tidak valid.")
        return value  # tidak dinormalisasi: fitur dihitung dari string persis seperti saat training

def create_app(
    manager: ModelManager | None = None,
    active_bundle: str | None = None,
    internal_token: str | None = None,
    laravel_url: str | None = None,
    retry_seconds: float | None = None,
) -> FastAPI:
    """Pabrik aplikasi. Jika `manager` tidak diberikan (produksi), semua nilai dibaca dari .env."""
    enable_docs = os.getenv("ENABLE_DOCS", "true").lower() == "true"
    bootstrap_model_id = None
    if manager is None:
        manager = ModelManager(_env_path("MODEL_REGISTRY_DIR", "models"))
        active_bundle = active_bundle or os.getenv("ACTIVE_MODEL_DIR", "").strip() or None
        bootstrap_model_id = _env_int("ACTIVE_MODEL_ID")
        if internal_token is None:
            internal_token = os.getenv("ML_INTERNAL_TOKEN", "").strip()
        if laravel_url is None:
            laravel_url = os.getenv("LARAVEL_BASE_URL", "").strip() or None
    config = InternalConfig(
        token=internal_token or "",
        laravel_url=laravel_url,
        bootstrap_bundle=active_bundle,
        bootstrap_model_id=bootstrap_model_id,
        retry_seconds=retry_seconds if retry_seconds is not None else _env_float("STARTUP_PULL_RETRY_SECONDS", 15.0),
    )

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        if config.problem:
            logger.warning("Endpoint internal dinonaktifkan: %s", config.problem)
        status = await asyncio.to_thread(sync_active_model, app)
        if status in ("laravel", "bootstrap", "aktif"):
            logger.info("Model aktif diperoleh (%s).", status)
        elif status == "menunggu":
            logger.warning("Belum ada model aktif; /predict menjawab 503 sampai model aktif tersedia.")
        retry_task = None
        if status in ("menunggu", "bootstrap") and config.laravel_url and not config.problem:
            retry_task = asyncio.create_task(retry_until_model(app))
        try:
            yield
        finally:
            if retry_task is not None:
                retry_task.cancel()
                with suppress(asyncio.CancelledError):
                    await retry_task

    app = FastAPI(
        title="PhishGuard API",
        version=API_VERSION,
        description="Layanan klasifikasi URL phishing berbasis Machine Learning.",
        lifespan=lifespan,
        docs_url="/docs" if enable_docs else None,
        redoc_url=None,
        openapi_url="/openapi.json" if enable_docs else None,
    )
    app.state.manager = manager
    app.state.internal = config
    app.state.model_op_lock = threading.Lock()

    @app.exception_handler(RequestValidationError)
    async def handle_validation(request: Request, exc: RequestValidationError):
        detail = "URL tidak valid." if request.url.path == "/predict" else "Permintaan tidak valid."
        return JSONResponse(status_code=422, content={"detail": detail})

    @app.exception_handler(ModelUnavailableError)
    async def handle_model_unavailable(request: Request, exc: ModelUnavailableError):
        return JSONResponse(status_code=503, content={"detail": "Model deteksi tidak dapat digunakan."})

    @app.exception_handler(Exception)
    async def handle_unexpected(request: Request, exc: Exception):
        logger.exception("Kesalahan tak terduga pada %s", request.url.path)
        return JSONResponse(status_code=500, content={"detail": "Terjadi kesalahan pada layanan deteksi."})

    @app.get("/", tags=["Info"])
    def root():
        return {"service": "PhishGuard API", "version": API_VERSION, "status": "running"}

    @app.get("/health", response_model=HealthResponse, tags=["Info"])
    def health(request: Request):
        current = request.app.state.manager.current
        return HealthResponse(
            status="ok" if current else "degraded",
            model_loaded=current is not None,
            model_name=current.name if current else None,
            model_version=current.version if current else None,
        )

    @app.get("/model", response_model=ModelInfoResponse, tags=["Model"])
    def model_info(request: Request):
        current = request.app.state.manager.current
        if current is None:
            raise ModelUnavailableError("Belum ada model aktif.")
        return ModelInfoResponse(**describe_model(current))

    @app.post("/predict", response_model=PredictResponse, tags=["Prediksi"])
    def predict(payload: PredictRequest, request: Request):
        return request.app.state.manager.predict(payload.url)

    app.include_router(internal_router)
    return app

def safe_joblib_load(path: Path) -> tuple[Any, list[str]]:
    """Muat file joblib dengan menolak objek di luar ALLOWED_GLOBALS.

    Mengembalikan (objek, daftar peringatan library). Penggantian find_class bersifat
    sementara dan dilindungi lock.
    """
    cls = _numpy_pickle.NumpyUnpickler
    has_own = "find_class" in vars(cls)
    original = cls.find_class

    def restricted(self, module, name):
        if (module, name) not in ALLOWED_GLOBALS:
            # Teks dari file yang tidak tepercaya hanya ditampilkan jika berbentuk nama Python yang wajar.
            if isinstance(module, str) and isinstance(name, str) and _IDENTIFIER.fullmatch(module) and _IDENTIFIER.fullmatch(name):
                raise UnsafeModelFileError(f"Objek tidak diizinkan di dalam file model: {module}.{name}")
            raise UnsafeModelFileError("File model rusak atau tidak dapat dibaca.")
        return original(self, module, name)

    with _LOAD_LOCK:
        cls.find_class = restricted
        try:
            with warnings.catch_warnings(record=True) as caught:
                warnings.simplefilter("always")
                obj = joblib.load(path)
        finally:
            if has_own:
                cls.find_class = original
            else:
                del cls.find_class
    return obj, [str(w.message) for w in caught]


def _sha256_stream(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()

@dataclass
class ValidationReport:
    checks: list[dict] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)

    def add(self, name: str, ok: bool, detail: str = "") -> bool:
        self.checks.append({"name": name, "ok": bool(ok), "detail": detail})
        return bool(ok)

    @property
    def ok(self) -> bool:
        return bool(self.checks) and all(c["ok"] for c in self.checks)

    @property
    def errors(self) -> list[str]:
        return [c["detail"] or c["name"] for c in self.checks if not c["ok"]]

    def to_dict(self) -> dict:
        return {
            "ok": self.ok,
            "valid": self.ok,
            "message": "Model kompatibel dengan sistem." if self.ok else "Model tidak kompatibel dengan sistem.",
            "errors": self.errors,
            "warnings": self.warnings,
            "checks": self.checks,
        }

def _is_number(value: Any) -> bool:
    return isinstance(value, (int, float)) and not isinstance(value, bool) and math.isfinite(value)


def _check_metadata(metadata: Any, names: Any) -> list[str]:
    """Kembalikan daftar masalah skema metadata (kosong jika valid)."""
    if not isinstance(metadata, dict):
        return ["metadata.json harus berupa objek JSON."]
    problems: list[str] = []
    for key in ("name", "version", "algorithm"):
        value = metadata.get(key)
        if not isinstance(value, str) or not value.strip() or len(value) > 100:
            problems.append(f"Field '{key}' wajib berupa teks tidak kosong (maksimal 100 karakter).")
    features = metadata.get("features")
    if not isinstance(features, list) or not features or not all(isinstance(f, str) for f in features):
        problems.append("Field 'features' wajib berupa daftar nama fitur.")
    count = metadata.get("feature_count")
    if not isinstance(count, int) or isinstance(count, bool):
        problems.append("Field 'feature_count' wajib berupa bilangan bulat.")
    sha = metadata.get("model_sha256")
    if not isinstance(sha, str) or not re.fullmatch(r"[0-9a-f]{64}", sha):
        problems.append("Field 'model_sha256' wajib berupa SHA-256 heksadesimal 64 karakter.")
    extractor = metadata.get("extractor")
    if not (isinstance(extractor, dict) and isinstance(extractor.get("version"), str)
            and isinstance(extractor.get("sha256"), str)):
        problems.append("Field 'extractor' wajib memuat 'version' dan 'sha256'.")
    metrics = metadata.get("metrics")
    needed = ("accuracy", "precision", "recall", "f1_score", "roc_auc")
    if not (isinstance(metrics, dict) and all(_is_number(metrics.get(k)) and 0 <= metrics[k] <= 1 for k in needed)):
        problems.append("Field 'metrics' wajib memuat accuracy, precision, recall, f1_score, roc_auc (0 sampai 1).")
    if not isinstance(names, list) or not all(isinstance(n, str) for n in names):
        problems.append("feature_names.json wajib berupa daftar nama fitur.")
    return problems


def _risk_thresholds(metadata: dict) -> tuple[float, float]:
    raw = metadata.get("risk_thresholds")
    if isinstance(raw, dict) and _is_number(raw.get("low")) and _is_number(raw.get("high")):
        low, high = float(raw["low"]), float(raw["high"])
        if 0 < low < high < 1:
            return low, high
    return DEFAULT_RISK_THRESHOLDS

def _library_differences(metadata: dict) -> list[str]:
    """Daftar library yang versinya berbeda dari saat training (untuk peringatan dan diagnosis)."""
    notes: list[str] = []
    for package in ("scikit-learn", "xgboost", "numpy", "joblib"):
        trained = (metadata.get("libraries") or {}).get(package)
        try:
            installed = importlib_metadata.version(package)
        except importlib_metadata.PackageNotFoundError:
            continue
        if trained and trained != installed:
            notes.append(f"{package}: training {trained}, terpasang {installed}")
    return notes

def build_indicators(features: dict[str, float], url: str) -> list[str]:
    """Indikator heuristik dari struktur URL. Bukan penjelasan langsung dari model."""
    found: list[str] = []
    if features["ip"]:
        found.append("Alamat host berupa IP, bukan nama domain.")
    if not features["is_https"]:
        found.append("URL tidak memakai HTTPS.")
    if features["nb_at"]:
        found.append("URL mengandung karakter '@'.")
    if features["punycode"]:
        found.append("Hostname memakai punycode (xn--), bisa dipakai untuk menyamarkan domain.")
    if features["shortening_service"]:
        found.append("URL memakai layanan pemendek tautan.")
    if features["tld_in_subdomain"]:
        found.append("Subdomain memuat ekstensi domain umum (mis. .com), pola penyamaran domain.")
    if features["abnormal_subdomain"]:
        found.append("Subdomain berbentuk tidak lazim (mis. ww2).")
    if features["nb_subdomains"] >= 3:
        found.append(f"Jumlah subdomain banyak ({int(features['nb_subdomains'])}).")
    if features["has_port"]:
        found.append("URL menyebut nomor port secara eksplisit.")
    if features["path_extension"]:
        found.append("Path berakhir dengan ekstensi berkas (.exe, .js, atau .txt).")
    if features["length_url"] > 75:
        found.append(f"URL sangat panjang ({int(features['length_url'])} karakter).")
    if features["ratio_digits_url"] >= 0.2:
        found.append("Proporsi angka pada URL tinggi.")
    lower = url.lower()
    keywords = [word for word in uf.PHISH_HINTS if word in lower]
    if keywords:
        found.append("Mengandung kata kunci yang sering dipakai phishing: " + ", ".join(keywords) + ".")
    if not found:
        found.append("Tidak ditemukan indikator mencurigakan pada struktur URL.")
    return found

def describe_model(loaded: LoadedModel, detail: bool = False) -> dict:
    """Ringkasan model untuk respons API. detail=True menambah data yang dibutuhkan tabel models di Laravel."""
    low, high = loaded.risk_thresholds
    info = {
        "model_id": loaded.model_id,
        "bundle_name": loaded.bundle_name,
        "name": loaded.name,
        "version": loaded.version,
        "algorithm": loaded.algorithm,
        "feature_count": len(loaded.features),
        "extractor_version": loaded.extractor_version,
        "model_sha256": loaded.model_sha256,
        "loaded_at": loaded.loaded_at,
        "metrics": {k: float(v) for k, v in loaded.metadata["metrics"].items()},
        "risk_thresholds": {"low": low, "high": high},
        "warnings": list(loaded.warnings),
    }
    if detail:
        dataset = loaded.metadata.get("dataset")
        dataset_name = dataset.get("name") if isinstance(dataset, dict) else dataset
        info["dataset_name"] = dataset_name if isinstance(dataset_name, str) else None
        info["description"] = loaded.metadata.get("description") if isinstance(loaded.metadata.get("description"), str) else None
        info["feature_names"] = list(loaded.features)
    return info

class ModelManager:
    """Memuat, memvalidasi, dan menyimpan satu model aktif untuk prediksi."""

    def __init__(self, registry_dir: Path, max_model_bytes: int = 100 * 1024 * 1024):
        self.registry_dir = Path(registry_dir).resolve()
        self.max_model_bytes = max_model_bytes
        self._current: LoadedModel | None = None
        self._swap_lock = threading.Lock()
        self._predict_lock = threading.Lock()  # prediksi diserialkan agar aman untuk library apa pun

    @property
    def current(self) -> LoadedModel | None:
        return self._current

    # ------------------------------------------------------------------ validasi
    def _resolve_bundle(self, bundle_name: str, report: ValidationReport) -> Path | None:
        if not isinstance(bundle_name, str) or not BUNDLE_NAME_PATTERN.fullmatch(bundle_name):
            report.add("Nama bundle valid", False, "Nama bundle tidak valid.")
            return None
        path = (self.registry_dir / bundle_name).resolve()
        if path.parent != self.registry_dir:
            report.add("Bundle berada di dalam registry", False, "Bundle berada di luar folder registry.")
            return None
        if not path.is_dir():
            report.add("Folder bundle ditemukan", False, f"Folder bundle '{bundle_name}' tidak ditemukan di registry.")
            return None
        report.add("Folder bundle ditemukan", True)
        return path

    def validate_bundle(self, bundle_name: str, model_id: int | None = None) -> tuple[LoadedModel | None, ValidationReport]:
        """Validasi lengkap. Tidak mengubah model aktif. Tidak melempar error untuk bundle yang buruk."""
        report = ValidationReport()
        bundle_dir = self._resolve_bundle(bundle_name, report)
        if bundle_dir is None:
            return None, report
        try:
            return self._validate(bundle_dir, bundle_name, model_id, report), report
        except Exception:  # noqa: BLE001 - detail hanya ke log server, bukan ke pengguna
            logger.exception("Validasi bundle '%s' gagal secara tak terduga", bundle_name)
            report.add("Validasi selesai tanpa kesalahan internal", False,
                       "Terjadi kesalahan internal saat memvalidasi model.")
            return None, report

    def _validate(self, bundle_dir: Path, bundle_name: str, model_id: int | None,
                  report: ValidationReport) -> LoadedModel | None:
        # 1. Berkas lengkap dan ukuran wajar
        missing = [f for f in REQUIRED_FILES if not (bundle_dir / f).is_file()]
        if not report.add("Berkas bundle lengkap", not missing,
                          f"Berkas tidak ditemukan: {', '.join(missing)}." if missing else ""):
            return None
        model_path = bundle_dir / "model.pkl"
        too_big = model_path.stat().st_size > self.max_model_bytes or any(
            (bundle_dir / f).stat().st_size > MAX_JSON_BYTES for f in ("metadata.json", "feature_names.json"))
        if not report.add("Ukuran berkas wajar", not too_big, "Ukuran berkas melebihi batas yang diizinkan."):
            return None

        # 2. Metadata dapat dibaca dan skemanya benar
        try:
            metadata = json.loads((bundle_dir / "metadata.json").read_text(encoding="utf-8"))
            names = json.loads((bundle_dir / "feature_names.json").read_text(encoding="utf-8"))
        except (OSError, ValueError):
            report.add("Metadata dapat dibaca", False, "metadata.json atau feature_names.json bukan JSON yang valid.")
            return None
        problems = _check_metadata(metadata, names)
        if not report.add("Metadata valid", not problems, " ".join(problems)):
            return None

        # 3. Kompatibilitas fitur (paling penting)
        model_features, current_features = list(names), list(uf.FEATURE_NAMES)
        count_ok = len(model_features) == len(current_features)
        report.add("Jumlah fitur sesuai", count_ok,
                   "" if count_ok else f"Model membutuhkan {len(model_features)} fitur, "
                                       f"sedangkan feature extractor saat ini menghasilkan {len(current_features)} fitur.")
        if count_ok:
            names_ok = model_features == current_features
            diff = next((i for i, (a, b) in enumerate(zip(model_features, current_features)) if a != b), None)
            report.add("Nama dan urutan fitur sesuai", names_ok,
                       "" if names_ok else f"Nama atau urutan fitur tidak sama dengan feature extractor saat ini "
                                           f"(posisi {diff + 1}: model '{model_features[diff]}', extractor '{current_features[diff]}').")
        consistent = metadata["features"] == model_features and metadata["feature_count"] == len(model_features)
        report.add("metadata.json konsisten dengan feature_names.json", consistent,
                   "" if consistent else "Daftar fitur atau feature_count di metadata.json tidak sama dengan feature_names.json.")
        extractor = metadata["extractor"]
        version_ok = extractor["version"] == uf.EXTRACTOR_VERSION
        report.add("Versi feature extractor sesuai", version_ok,
                   "" if version_ok else f"Model dilatih dengan extractor versi {extractor['version']}, "
                                         f"sedangkan sistem memakai versi {uf.EXTRACTOR_VERSION}.")
        sha_ok = extractor["sha256"] in extractor_hashes()
        report.add("Hash feature extractor sesuai", sha_ok,
                   "" if sha_ok else "url_features.py berbeda dari yang dipakai saat training (hash tidak sama).")
        if not report.ok:
            return None

        actual_sha = _sha256_stream(model_path)
        if not report.add("Hash file model cocok", actual_sha == metadata["model_sha256"],
                          "SHA-256 model.pkl tidak sama dengan yang tercatat di metadata.json."):
            return None

        # 5. Pemuatan aman (perbedaan versi library dicatat dulu agar terlihat walau pemuatan gagal)
        version_notes = _library_differences(metadata)
        report.warnings.extend(f"Versi library berbeda: {note}" for note in version_notes)
        try:
            model, load_warnings = safe_joblib_load(model_path)
        except UnsafeModelFileError as exc:
            report.add("File model aman dimuat", False, str(exc))
            return None
        except Exception:  # noqa: BLE001

            return None

        has_proba = callable(getattr(model, "predict_proba", None))
        classes = getattr(model, "classes_", None)
        classes_ok = classes is not None and [int(c) for c in classes] == [0, 1]
        n_in = getattr(model, "n_features_in_", len(model_features))
        report.add("Model punya predict_proba", has_proba, "Model tidak memiliki method predict_proba.")
        report.add("Kelas model [0, 1]", classes_ok, "Kelas model harus [0, 1] dengan 1 = phishing.")
        report.add("Jumlah fitur model sesuai", n_in == len(model_features),
                   f"Model dilatih dengan {n_in} fitur, sedangkan daftar fitur berisi {len(model_features)}.")
        if not report.ok:
            return None

class FailedAuthLimiter:
    """Membatasi percobaan token yang salah per alamat klien (jendela waktu geser)."""

    def __init__(self, max_failures: int = 5, window_seconds: float = 60.0):
        self.max_failures = max_failures
        self.window = window_seconds
        self._failures: dict[str, deque] = defaultdict(deque)
        self._lock = threading.Lock()

    def _purge(self, key: str, now: float) -> deque:
        queue = self._failures[key]
        while queue and now - queue[0] > self.window:
            queue.popleft()
        return queue

    def blocked(self, key: str) -> bool:
        with self._lock:
            return len(self._purge(key, time.monotonic())) >= self.max_failures

    def record(self, key: str) -> None:
        with self._lock:
            now = time.monotonic()
            self._purge(key, now).append(now)

    def reset(self, key: str) -> None:
        with self._lock:
            self._failures.pop(key, None)

def require_internal_token(request: Request) -> None:
    config: InternalConfig = request.app.state.internal
    if config.problem:
        raise HTTPException(status_code=503, detail="Endpoint internal belum dikonfigurasi.")
    client = request.client.host if request.client else "tidak-diketahui"
    if config.limiter.blocked(client):
        raise HTTPException(status_code=429, detail="Terlalu banyak percobaan. Coba lagi nanti.",
                            headers={"Retry-After": str(int(config.limiter.window))})
    supplied = request.headers.get("X-Internal-Token", "")
    if not hmac.compare_digest(supplied.encode("utf-8"), config.token.encode("utf-8")):
        config.limiter.record(client)
        raise HTTPException(status_code=401, detail="Token internal tidak valid.")
    config.limiter.reset(client)

    """Hanya satu operasi model (muat/validasi/aktifkan) berjalan pada satu waktu."""

def fetch_active_model(base_url: str, token: str, timeout: float = 3.0) -> dict:
    """GET {base}/api/internal/active-model -> {"bundle_name": str | null, "model_id": int | null}."""
    url = base_url.rstrip("/") + "/api/internal/active-model"
    try:
        with httpx.Client(timeout=timeout, follow_redirects=False) as client:
            response = client.get(url, headers={"X-Internal-Token": token, "Accept": "application/json"})
        if response.status_code != 200:
            raise LaravelUnavailable(f"Laravel menjawab HTTP {response.status_code}.")
        data = response.json()
    except LaravelUnavailable:
        raise
    except (httpx.HTTPError, ValueError) as exc:
        raise LaravelUnavailable(f"Gagal menghubungi Laravel: {type(exc).__name__}.") from exc

    if not isinstance(data, dict) or "bundle_name" not in data:
        raise LaravelUnavailable("Jawaban Laravel tidak sesuai kontrak (bentuk JSON).")
    bundle = data.get("bundle_name")
    model_id = data.get("model_id")
    if bundle is not None and not (isinstance(bundle, str) and BUNDLE_NAME_PATTERN.fullmatch(bundle)):
        raise LaravelUnavailable("Jawaban Laravel tidak sesuai kontrak (bundle_name).")
    if model_id is not None and not (isinstance(model_id, int) and not isinstance(model_id, bool) and model_id >= 1):
        raise LaravelUnavailable("Jawaban Laravel tidak sesuai kontrak (model_id).")
    return {"bundle_name": bundle, "model_id": model_id}


def sync_active_model(app) -> str:
    """Tentukan model aktif saat startup. Hasil: 'laravel', 'bootstrap', 'aktif', 'gagal', atau 'menunggu'.

    Jika Laravel dapat dihubungi dan menyebut model aktif, Laravel dipercaya sepenuhnya: jika model itu
    gagal divalidasi, tidak ada model pengganti (agar scan tidak tercatat pada model yang salah).
    ACTIVE_MODEL_DIR hanya dipakai jika Laravel tidak dapat dihubungi atau belum punya model aktif.
    """
    config: InternalConfig = app.state.internal
    manager: ModelManager = app.state.manager
    with model_operation(app):
        if manager.current is not None:
            return "aktif"
        if config.laravel_url and config.problem is None:
            try:
                info = fetch_active_model(config.laravel_url, config.token)
            except LaravelUnavailable as exc:
                config.pull_failures += 1
                if config.pull_failures == 1 or config.pull_failures % 20 == 0:
                    logger.warning("Model aktif belum bisa ditarik dari Laravel (percobaan ke-%d): %s",
                                   config.pull_failures, exc)
            else:
                if info["bundle_name"]:
                    report = manager.activate_bundle(info["bundle_name"], info["model_id"])
                    if report.ok:
                        return "laravel"
                    logger.error("Model aktif dari Laravel '%s' gagal divalidasi: %s", info["bundle_name"], report.errors)
                    return "gagal"
        if config.bootstrap_bundle:
            report = manager.activate_bundle(config.bootstrap_bundle, config.bootstrap_model_id)
            if report.ok:
                return "bootstrap"
            logger.error("Model awal '%s' gagal dimuat: %s", config.bootstrap_bundle, report.errors)
            return "gagal"
    return "menunggu"

namespace App\Services;

use App\Exceptions\MlServiceException;
use Illuminate\Http\Client\ConnectionException;
use Illuminate\Http\Client\PendingRequest;
use Illuminate\Http\Client\Response;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;
use InvalidArgumentException;

/**
 * Penghubung Laravel ke FastAPI. Hanya memakai HTTP (Http::), tidak pernah menjalankan Python
 * lewat shell. Semua kegagalan diubah menjadi MlServiceException dengan pesan yang aman untuk
 * pengguna; rincian teknis hanya masuk ke log server.
 */
class PhishGuardService
{
    /**
     * Minta prediksi untuk satu URL.
     *
     * @throws MlServiceException
     */
    public function predict(string $url): PredictionResult
    {
        $url = trim($url);
        if ($url === '' || mb_strlen($url, 'UTF-8') > (int) config('phishguard.scan.max_url_length', 2048)) {
            throw MlServiceException::invalidUrl();
        }

        try {
            $response = $this->client()->post('/predict', ['url' => $url]);
        } catch (ConnectionException $e) {
            Log::warning('FastAPI tidak dapat dihubungi saat prediksi.', ['error' => $e->getMessage()]);
            throw MlServiceException::unavailable($e);
        }

        return $this->parsePrediction($response, $url);
    }

    /**
     * Status singkat layanan ML. Tidak pernah melempar error.
     *
     * @return array{reachable: bool, model_loaded: bool, model_name: ?string, model_version: ?string}
     */
    public function health(): array
    {
        $down = ['reachable' => false, 'model_loaded' => false, 'model_name' => null, 'model_version' => null];

        try {
            $response = $this->client()->timeout(3)->get('/health');
        } catch (ConnectionException) {
            return $down;
        }

        $data = $response->json();
        if ($response->status() !== 200 || ! is_array($data) || ! is_bool($data['model_loaded'] ?? null)) {
            return $down;
        }

        $health = [
            'reachable' => true,
            'model_loaded' => $data['model_loaded'],
            'model_name' => is_string($data['model_name'] ?? null) ? $data['model_name'] : null,
            'model_version' => is_string($data['model_version'] ?? null) ? $data['model_version'] : null,
        ];

        // Sinkronisasi otomatis: jika model di FastAPI berbeda dari model aktif di database, minta FastAPI memuat model aktif DB
        if ($health['reachable'] && class_exists(\App\Models\MlModel::class)) {
            try {
                $activeModel = \App\Models\MlModel::getActiveModel();
                if ($activeModel && ($health['model_name'] !== $activeModel->name || $health['model_version'] !== $activeModel->version)) {
                    $reload = $this->reloadModel($activeModel->bundle_name, $activeModel->id);
                    if ($reload['ok'] ?? false) {
                        $health['model_name'] = $activeModel->name;
                        $health['model_version'] = $activeModel->version;
                        $health['model_loaded'] = true;
                    }
                }
            } catch (\Throwable $e) {

            }
        }

        return $health;
    }

     *
     * @return array{ok: bool, errors: array, warnings: array, model: ?array}
     */
    public function validateModel(string $bundleName, ?int $modelId = null): array
    {
        $token = config('phishguard.ml.internal_token');
        try {
            $response = $this->client()
                ->withHeader('X-Internal-Token', $token)
                ->timeout(15)
                ->post('/internal/validate-model', [
                    'bundle_name' => $bundleName,
                    'model_id' => $modelId,
                ]);

            return $response->json() ?? ['ok' => false, 'errors' => ['Respon server tidak valid']];
        } catch (ConnectionException $e) {
            return ['ok' => false, 'errors' => ['Tidak dapat menghubungi layanan FastAPI: ' . $e->getMessage()]];
        }
    }

    /**
     * Meminta FastAPI memvalidasi dan mengaktifkan bundle model sebagai active model.
     *
     * @return array{ok: bool, message: string, errors: array}
     */
    public function reloadModel(string $bundleName, ?int $modelId = null): array
    {
        $token = config('phishguard.ml.internal_token');
        try {
            $response = $this->client()
                ->withHeader('X-Internal-Token', $token)
                ->timeout(20)
                ->post('/internal/reload-model', [
                    'bundle_name' => $bundleName,
                    'model_id' => $modelId,
                ]);

            if ($response->successful()) {
                return ['ok' => true, 'message' => 'Model berhasil diaktifkan di AI Engine.', 'errors' => []];
            }

            $body = $response->json() ?? [];
            return [
                'ok' => false,
                'message' => 'Gagal mengaktifkan model di AI Engine.',
                'errors' => $body['errors'] ?? [$response->body()],
            ];
        } catch (ConnectionException $e) {
            return ['ok' => false, 'message' => 'Gagal menghubungi FastAPI.', 'errors' => [$e->getMessage()]];
        }
    }

    private function parsePrediction(Response $response, string $url): PredictionResult
    {
        $status = $response->status();

        if ($status === 422) {
            throw MlServiceException::invalidUrl();
        }
        if ($status === 503) {
            throw MlServiceException::modelUnavailable();
        }
        if ($status !== 200) {
            Log::error('Jawaban FastAPI tidak terduga.', ['status' => $status]);
            throw MlServiceException::unavailable();
        }

        $data = $response->json();
        if (! is_array($data)) {
            Log::error('Jawaban FastAPI bukan JSON objek.');
            throw MlServiceException::unavailable();
        }

        try {
            return PredictionResult::fromArray($data, $url);
        } catch (InvalidArgumentException $e) {
            Log::error('Jawaban FastAPI tidak sesuai kontrak.', ['alasan' => $e->getMessage()]);
            throw MlServiceException::unavailable($e);
        }
    }

    private function client(): PendingRequest
    {
        $config = config('phishguard.ml');

        return Http::baseUrl(rtrim((string) $config['base_url'], '/'))
            ->timeout((float) $config['timeout'])
            ->connectTimeout((float) $config['connect_timeout'])
            ->acceptJson()
            ->asJson()
            ->withUserAgent('PhishGuard-Laravel/1.0');
    }

<?php

namespace App\Services;

use InvalidArgumentException;

/**
 * Hasil prediksi dari FastAPI yang sudah divalidasi. Jawaban yang melanggar kontrak ditolak,
 * sehingga data yang tidak masuk akal tidak pernah sampai ke database atau tampilan.
 */
final readonly class PredictionResult
{
    public const PREDICTIONS = ['Legitimate', 'Phishing'];

    public const RISK_LEVELS = ['Low', 'Medium', 'High'];

    /** @param list<string> $indicators */
    public function __construct(
        public string $url,
        public string $prediction,
        public float $probability,
        public int $riskScore,
        public string $riskLevel,
        public ?int $modelId,
        public string $modelName,
        public string $modelVersion,
        public string $message,
        public array $indicators,
    ) {
    }

    public function isPhishing(): bool
    {
        return $this->prediction === 'Phishing';
    }

    /**
     * @param  array<string, mixed>  $data  Isi JSON jawaban /predict
     * @param  string  $expectedUrl  URL yang dikirim; jawaban harus menyebut URL yang sama
     *
     * @throws InvalidArgumentException jika ada field yang hilang, bertipe salah, atau tidak konsisten
     */
    public static function fromArray(array $data, string $expectedUrl): self
    {
        foreach (['url', 'prediction', 'probability', 'risk_score', 'risk_level', 'model_name', 'model_version', 'message', 'indicators'] as $key) {
            if (! array_key_exists($key, $data)) {
                throw new InvalidArgumentException("Field '{$key}' tidak ada.");
            }
        }

        if (! is_string($data['url']) || $data['url'] !== $expectedUrl) {
            throw new InvalidArgumentException('URL pada jawaban berbeda dari URL yang dikirim.');
        }
        if (! is_string($data['prediction']) || ! in_array($data['prediction'], self::PREDICTIONS, true)) {
            throw new InvalidArgumentException("Nilai 'prediction' tidak dikenal.");
        }
        if (! (is_int($data['probability']) || is_float($data['probability'])) || $data['probability'] < 0.5 || $data['probability'] > 1) {
            throw new InvalidArgumentException("Nilai 'probability' harus antara 0,5 dan 1.");
        }
        if (! is_int($data['risk_score']) || $data['risk_score'] < 0 || $data['risk_score'] > 100) {
            throw new InvalidArgumentException("Nilai 'risk_score' harus bilangan bulat 0 sampai 100.");
        }
        if (! is_string($data['risk_level']) || ! in_array($data['risk_level'], self::RISK_LEVELS, true)) {
            throw new InvalidArgumentException("Nilai 'risk_level' tidak dikenal.");
        }

        // Konsistensi: prediksi Phishing berarti probabilitas phishing >= 0,5, begitu pula sebaliknya.
        if ($data['prediction'] === 'Phishing' && $data['risk_score'] < 50) {
            throw new InvalidArgumentException("'risk_score' tidak sesuai dengan prediksi Phishing.");
        }
        if ($data['prediction'] === 'Legitimate' && $data['risk_score'] > 50) {
            throw new InvalidArgumentException("'risk_score' tidak sesuai dengan prediksi Legitimate.");
        }

        $modelId = $data['model_id'] ?? null;
        if ($modelId !== null && (! is_int($modelId) || $modelId < 1)) {
            throw new InvalidArgumentException("Nilai 'model_id' harus bilangan bulat positif atau null.");
        }
        if (! is_string($data['model_name']) || $data['model_name'] === '' || mb_strlen($data['model_name']) > 100) {
            throw new InvalidArgumentException("Nilai 'model_name' tidak valid.");
        }
        if (! is_string($data['model_version']) || $data['model_version'] === '' || mb_strlen($data['model_version']) > 50) {
            throw new InvalidArgumentException("Nilai 'model_version' tidak valid.");
        }
        if (! is_string($data['message']) || mb_strlen($data['message']) > 500) {
            throw new InvalidArgumentException("Nilai 'message' tidak valid.");
        }

        $indicators = $data['indicators'];
        if (! is_array($indicators) || ! array_is_list($indicators) || count($indicators) > 20) {
            throw new InvalidArgumentException("Nilai 'indicators' harus daftar maksimal 20 teks.");
        }
        foreach ($indicators as $indicator) {
            if (! is_string($indicator) || mb_strlen($indicator) > 500) {
                throw new InvalidArgumentException("Isi 'indicators' harus teks maksimal 500 karakter.");
            }
        }

        return new self(
            url: $data['url'],
            prediction: $data['prediction'],
            probability: (float) $data['probability'],
            riskScore: $data['risk_score'],
            riskLevel: $data['risk_level'],
            modelId: $modelId,
            modelName: $data['model_name'],
            modelVersion: $data['model_version'],
            message: $data['message'],
            indicators: $indicators,
        );
    }

    /** @return array<string, mixed> */
    public function toArray(): array
    {
        return [
            'url' => $this->url,
            'prediction' => $this->prediction,
            'probability' => $this->probability,
            'risk_score' => $this->riskScore,
            'risk_level' => $this->riskLevel,
            'model_id' => $this->modelId,
            'model_name' => $this->modelName,
            'model_version' => $this->modelVersion,
            'message' => $this->message,

    /**
     * Lakukan autentikasi kredensial pengguna dengan proteksi rate limiting.
     *
     * @throws \Illuminate\Validation\ValidationException
     */
    public function authenticate(): void
    {
        $this->ensureIsNotRateLimited();

        if (! Auth::attempt($this->only('email', 'password'), $this->boolean('remember'))) {
            RateLimiter::hit($this->throttleKey());

            throw ValidationException::withMessages([
                'email' => 'Email atau kata sandi yang Anda masukkan salah.',
            ]);
        }

        RateLimiter::clear($this->throttleKey());
    }

     *
     * @throws \Illuminate\Validation\ValidationException
     */
    public function ensureIsNotRateLimited(): void
    {
        if (! RateLimiter::tooManyAttempts($this->throttleKey(), 5)) {
            return;
        }

        event(new Lockout($this));

        $seconds = RateLimiter::availableIn($this->throttleKey());

        throw ValidationException::withMessages([
            'email' => "Terlalu banyak percobaan login. Silakan coba lagi dalam {$seconds} detik.",
        ]);
    }

    /**
     * Dapatkan throttle key untuk rate limiter berdasarkan email dan IP.
     */

    {
        return Str::transliterate(Str::lower($this->string('email')).'|'.$this->ip());

            'version' => ['required', 'string', 'max:50', 'regex:/^[a-zA-Z0-9\.\_\-]+$/'],
            'algorithm' => ['required', 'string', 'max:50'],
            'description' => ['nullable', 'string', 'max:1000'],
        ]);

        $file = $request->file('model_archive');
        $bundleName = Str::slug($request->algorithm . '_' . $request->version, '_');

        // Target path penyimpanan internal ML models
        $targetDir = base_path('../ml/models/' . $bundleName);

        if (File::exists($targetDir)) {
            return back()->withInput()->with('error', "Bundle model dengan nama '{$bundleName}' sudah ada. Silakan gunakan versi yang berbeda.");
        }

        // Validasi ketersediaan ekstensi PHP ZipArchive
        if (! class_exists('ZipArchive')) {
            return back()->withInput()->with('error', 'Ekstensi PHP "zip" belum aktif di server Anda. Harap aktifkan "extension=zip" di file php.ini dan restart server.');
        }

        // Ekstrak ZIP bundle dengan proteksi Path Traversal (Zip Slip)
        $zip = new ZipArchive();
        if ($zip->open($file->getRealPath()) === true) {
            for ($i = 0; $i < $zip->numFiles; $i++) {
                $entryName = $zip->getNameIndex($i);
                if (str_contains($entryName, '..') || str_starts_with($entryName, '/') || str_starts_with($entryName, '\\')) {
                    $zip->close();
                    return back()->withInput()->with('error', 'Arsip zip tidak valid (terdeteksi path traversal).');
                }
            }

            File::makeDirectory($targetDir, 0755, true);
            $zip->extractTo($targetDir);
            $zip->close();
        } else {
            return back()->withInput()->with('error', 'Gagal mengekstrak berkas arsip zip model.');
        }

        // Periksa keberadaan berkas wajib: model.pkl, metadata.json, feature_names.json
        $modelPkl = $targetDir . '/model.pkl';
        $metadataJson = $targetDir . '/metadata.json';
        $featuresJson = $targetDir . '/feature_names.json';

        if (! File::exists($modelPkl) || ! File::exists($metadataJson) || ! File::exists($featuresJson)) {
            File::deleteDirectory($targetDir);
            return back()->withInput()->with('error', 'Bundle zip tidak lengkap! Wajib memuat berkas: model.pkl, metadata.json, dan feature_names.json.');
        }

        // Baca metadata
        $meta = json_decode(File::get($metadataJson), true) ?? [];
        $features = json_decode(File::get($featuresJson), true) ?? [];

        $fileHash = hash_file('sha256', $modelPkl);

        // Ekstraksi metrik secara fleksibel dari berbagai format metadata.json
        $balanced = $meta['final_test_set_metrics_before_refit']['balanced_mode'] ?? [];
        $finalMetrics = $meta['final_test_set_metrics_before_refit'] ?? [];
        $rawMetrics = $meta['metrics'] ?? [];

        $accuracy = (float) ($rawMetrics['accuracy'] ?? $balanced['accuracy'] ?? $finalMetrics['accuracy'] ?? 0.85);
        $precision = (float) ($rawMetrics['precision'] ?? $balanced['precision'] ?? $finalMetrics['precision'] ?? 0.85);
        $recall = (float) ($rawMetrics['recall'] ?? $balanced['recall'] ?? $finalMetrics['recall'] ?? 0.85);
        $f1Score = (float) ($rawMetrics['f1_score'] ?? $balanced['f1_score'] ?? $finalMetrics['f1_score'] ?? 0.85);
        $rocAuc = (float) ($rawMetrics['roc_auc'] ?? $finalMetrics['roc_auc'] ?? $balanced['roc_auc'] ?? 0.90);

        // Simpan ke database dengan status INACTIVE
        $newModel = MlModel::create([
            'name' => $request->name,
            'version' => $request->version,
            'algorithm' => $request->algorithm,
            'bundle_name' => $bundleName,
            'file_path' => 'models/' . $bundleName . '/model.pkl',
            'file_hash' => $fileHash,
            'dataset_name' => $meta['dataset']['name'] ?? 'Hannousse & Yahiouche Dataset B',
            'feature_count' => count($features),
            'feature_names' => $features,
            'accuracy' => $accuracy,
            'precision' => $precision,
            'recall' => $recall,
            'f1_score' => $f1Score,
            'roc_auc' => $rocAuc,
            'description' => $request->description ?? ($meta['description'] ?? ($meta['reason_for_selection'] ?? null)),
            'status' => MlModel::STATUS_INACTIVE,
            'uploaded_by' => Auth::id(),
        ]);

        ActivityLog::record(
            ActivityLog::UPLOAD_MODEL,
            "Admin mengunggah model baru: {$newModel->name} v{$newModel->version} (Bundle: {$bundleName})"
        );

        return redirect()->route('admin.models.show', $newModel->id)
            ->with('success', 'Model berhasil diunggah! Silakan lakukan validasi sebelum aktivasi.');
    }

    /**
     * PHASE 30: Aktivasi model menjadi Active Model produksi.
     */
    public function activate(Request $request, int $id): RedirectResponse
    {
        $model = MlModel::findOrFail($id);
        $currentActive = MlModel::getActiveModel();

        if ($currentActive && $currentActive->id === $model->id) {
            return back()->with('error', 'Model ini sudah berstatus aktif.');
        }

        // Panggil FastAPI reload-model
        $reload = $this->service->reloadModel($model->bundle_name, $model->id);

        if (! ($reload['ok'] ?? false)) {
            $err = implode(', ', $reload['errors'] ?? ['AI engine menolak aktivasi']);
            return back()->with('error', "Gagal mengaktifkan model di AI engine: {$err}");
        }

        // Update database: Nonaktifkan model lama
        if ($currentActive) {
            $currentActive->update(['status' => MlModel::STATUS_INACTIVE]);
        }

        // Aktifkan model baru
        $model->update([
            'status' => MlModel::STATUS_ACTIVE,
            'activated_by' => Auth::id(),
            'activated_at' => now(),
        ]);

        // Catat di model activation logs
        ModelActivationLog::create([
            'previous_model_id' => $currentActive?->id,
            'new_model_id' => $model->id,
            'action' => ModelActivationLog::ACTION_ACTIVATE,
            'admin_id' => Auth::id(),
            'reason' => $request->input('reason', 'Aktivasi model produksi oleh administrator.'),
        ]);

        // Catat activity log
        ActivityLog::record(
            ActivityLog::ACTIVATE_MODEL,
            "Admin mengaktifkan model {$model->name} v{$model->version} menggantikan " . ($currentActive ? "{$currentActive->name} v{$currentActive->version}" : 'tidak ada')
        );

        return redirect()->route('admin.models.active')->with('success', "Model {$model->name} v{$model->version} berhasil diaktifkan sebagai model produksi!");
    }

    public function rollback(Request $request, int $id): RedirectResponse
    {
        $targetModel = MlModel::findOrFail($id);
        $currentActive = MlModel::getActiveModel();

        if ($targetModel->isActive()) {
            return back()->with('error', 'Model ini sedang aktif saat ini.');
        }

        $reload = $this->service->reloadModel($targetModel->bundle_name, $targetModel->id);
        if (! ($reload['ok'] ?? false)) {
            return back()->with('error', 'Gagal melakukan rollback di AI Engine.');
        }

        if ($currentActive) {
            $currentActive->update(['status' => MlModel::STATUS_INACTIVE]);
        }

        $targetModel->update([
            'status' => MlModel::STATUS_ACTIVE,
            'activated_by' => Auth::id(),
            'activated_at' => now(),
        ]);

        ModelActivationLog::create([
            'previous_model_id' => $currentActive?->id,
            'new_model_id' => $targetModel->id,
            'action' => ModelActivationLog::ACTION_ROLLBACK,
            'admin_id' => Auth::id(),
            'reason' => $request->input('reason', 'Rollback ke versi sebelumnya oleh administrator.'),
        ]);

        ActivityLog::record(
            ActivityLog::ROLLBACK_MODEL,
            "Admin melakukan rollback model ke {$targetModel->name} v{$targetModel->version}"
        );

        return redirect()->route('admin.models.active')->with('success', "Rollback berhasil! Model {$targetModel->name} v{$targetModel->version} kini aktif kembali.");
    }

    }
